Create docs/DEPLOYMENT_GUIDE.md (mkdir docs/ if needed). This guide walks through complete deployment from zero to production.

Structure following 08-RESEARCH.md Pattern 3, expanded:

## 1. Prerequisites
- Windows Server 2019+ or Windows 10/11 Pro
- Python 3.11+ installed (download from python.org, check "Add to PATH" during install)
- Administrator access to the server
- Network access to: Azure Portal, Apify, internet (for news sources)
- Azure subscription with:
  - Azure OpenAI service provisioned
  - Permission to register applications in Microsoft Entra ID
  - Azure Blob Storage account (for backups)

## 2. Installation (15 minutes)
Step-by-step:
1. Copy project files to server (e.g., C:\MDInsights)
2. Open Command Prompt as Administrator
3. Create virtual environment: `python -m venv venv`
4. Activate: `venv\Scripts\activate`
5. Install dependencies: `pip install -r requirements.txt`
6. Copy .env.example to .env: `copy .env.example .env`
7. Create data directory: `mkdir data`

## 3. Azure AD App Registration (20 minutes)
This is the most critical section. Step-by-step with specific portal paths:

1. Sign in to Microsoft Entra admin center (https://entra.microsoft.com)
2. Navigate: Identity > Applications > App registrations
3. Click "+ New registration"
   - Name: "MDInsights Intelligence Brief"
   - Supported account types: "Accounts in this organizational directory only"
   - Redirect URI: Leave blank (not needed for daemon app)
   - Click Register
4. Copy from Overview page:
   - Application (client) ID -> MICROSOFT_CLIENT_ID in .env
   - Directory (tenant) ID -> MICROSOFT_TENANT_ID in .env
5. Navigate: Certificates & secrets > Client secrets > + New client secret
   - Description: "MDInsights production"
   - Expiry: 24 months (set calendar reminder to renew)
   - Copy secret Value (shown only once!) -> MICROSOFT_CLIENT_SECRET in .env
6. Navigate: API permissions > + Add a permission
   - Microsoft Graph > Application permissions
   - Search and add: Mail.Send
   - Click "Grant admin consent for [organization]" (requires admin)
7. Verify: API permissions page shows Mail.Send with green checkmark (admin consent granted)

IMPORTANT: The client secret value is shown only once when created. If lost, create a new one.
IMPORTANT: Admin consent is required for Mail.Send application permission. Contact your Azure AD administrator if you cannot grant consent.

## 4. Azure OpenAI Configuration (10 minutes)
1. Azure Portal > Azure OpenAI > [your resource]
2. Navigate: Keys and Endpoint
3. Copy:
   - Endpoint URL -> AZURE_OPENAI_ENDPOINT (include trailing /)
   - Key 1 -> AZURE_OPENAI_API_KEY
4. Navigate: Model deployments > Manage Deployments
5. Verify gpt-4o deployment exists, copy deployment name -> AZURE_OPENAI_DEPLOYMENT

## 5. Apify Configuration (5 minutes)
1. Sign in to Apify Console (https://console.apify.com)
2. Navigate: Settings > Integrations
3. Copy API Token -> APIFY_TOKEN in .env

## 6. Azure Blob Storage for Backups (10 minutes)
1. Azure Portal > Storage accounts > [your account]
2. Navigate: Containers > + Container
   - Name: "mdinsights-backups"
   - Access level: Private
3. Navigate: Access keys
4. Copy Connection string -> AZURE_STORAGE_CONNECTION_STRING

## 7. Database Initialization (5 minutes)
1. From project directory (with venv activated):
   ```
   python scripts/seed_sources.py
   ```
2. Verify: `sqlite3 data/mdinsights.db "SELECT COUNT(*) FROM sources;"`
   Should return 18+ sources

## 8. Task Scheduler Configuration (10 minutes)
1. Open PowerShell as Administrator
2. Navigate to project deploy/ directory
3. Run: `.\setup_task.ps1`
   Or with custom path: `.\setup_task.ps1 -ProjectPath "C:\MDInsights"`
4. Verify 4 tasks created:
   - Open Task Scheduler (Start > search "Task Scheduler")
   - Under Task Scheduler Library, verify:
     - MDInsights Daily Pipeline (06:00 daily)
     - MDInsights Daily Pipeline - Backup (07:00 daily)
     - MDInsights Daily Pipeline - Drift Check (Monday 08:00)
     - MDInsights Daily Pipeline - Monitor (09:00 daily)

## 9. Web Server Configuration (5 minutes)
1. Test local access: `python -m app.main` then open http://localhost:8001/admin
2. For production: Configure as Windows Service or use Task Scheduler to start on boot
3. Firewall: Open port 8001 for internal access if dashboard needs to be accessible from other machines

## 10. Validation (10 minutes)
1. Run production readiness check: `python scripts/validate_production_ready.py`
2. Test pipeline manually: Visit /admin/trigger, click "Run Pipeline Now"
3. Verify email delivery: Check recipient inboxes
4. Verify backup: `python scripts/backup_db.py`, check Azure Blob container

## 11. Production Checklist
Comprehensive checklist (checkboxes) covering:
- [ ] Python 3.11+ installed and on PATH

- [ ] .env file configured with all required values
- [ ] Azure AD app registered with Mail.Send permission (admin consent granted)

## 12. Maintenance Notes
- **Client secret expiry:** Azure AD client secrets expire. Set a calendar reminder 2 weeks before expiry to rotate.
- **Log rotation:** Logs auto-rotate daily, 30-day retention. No manual cleanup needed.
- **Backup retention:** Azure Blob backups auto-clean after BACKUP_RETENTION_DAYS (default 30).
- **Source updates:** If a news source changes its website structure, the Apify actor may need updating. Contact developer.

## Appendix B: Troubleshooting Deployment Issues
Common deployment problems:
- Python not found: Reinstall with "Add to PATH" checked
- pip install fails: Check internet connectivity, try `pip install --trusted-host pypi.org`
- Azure AD consent error: Contact Azure AD administrator
- Task Scheduler "Access Denied": Run PowerShell as Administrator
- Port 8001 already in use: Change PORT in .env
