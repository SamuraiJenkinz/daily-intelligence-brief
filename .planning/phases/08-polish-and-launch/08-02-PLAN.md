## 1. Quick Start (What MDInsights Does)
- One-paragraph system overview: "MDInsights collects news from 18+ insurance sources, classifies them by priority and audience role using AI, and delivers tailored intelligence briefs to Brokers, Leadership, Compliance, and Underwriting teams each morning."
- How to access admin dashboard: Open browser, go to http://[server-address]:8001/admin
- What happens automatically each day:
  - 06:00 — Pipeline runs (collect articles, classify, generate briefs, send emails)
  - 07:00 — Database backup to Azure Blob Storage
  - Monday 08:00 — Classification drift check
  - 09:00 — Monitoring check (verifies pipeline ran, sends alert if failed)
- When administrator action is needed: Only when alerts arrive or changes requested

## 2. Daily Operations
- Normal day: System runs automatically, no action needed
- Checking system status: Navigate to /admin dashboard, review "Last Run" status
- Viewing today's reports: Admin dashboard > Archive page, select today's date
- Understanding the dashboard statistics: article count, source count, last run time

## 3. Source Management
Step-by-step with expected UI behavior:
- **Viewing sources:** Navigate to /admin/sources, see list with status indicators
- **Adding a new source:** Click "Add Source" button, fill form fields:
  - Name (required): Display name for the source
  - URL (required): Source website URL
  - Source Type: Select from Apify/RSS
  - Apify Actor ID (if Apify type): The Apify actor identifier
  - Enabled: Toggle on/off
- **Editing a source:** Click edit icon on source row, modify fields, click Save
- **Disabling a source:** Click toggle to disable (source stays in database but stops collecting)
- **Deleting a source:** Click delete icon, confirm deletion
- **Monitoring source health:** Dashboard shows articles-per-run baseline. If a source drops below threshold, health alert email is sent.

## 4. Recipient Management
Step-by-step:
- **Viewing recipients:** Navigate to /admin/recipients
- **Managing recipients for each role:** Each role (Brokers, Leadership, Compliance, Underwriting) has TO, CC, and BCC fields
- **Adding a recipient:** Type email address in the appropriate field, click Save
- **Removing a recipient:** Remove email from the field, click Save
- **Multiple recipients:** Separate with commas (e.g., user1@marsh.com, user2@marsh.com)
- **Testing email delivery:** Use /admin/trigger to run a test pipeline, verify recipients receive emails

## 5. Report Archive and Search
- **Browsing past reports:** /admin/archive — select date and role to view
- **Searching articles:** /admin/search — type keywords, filter by date range, source, or role
- **Search tips:** Search matches article titles and content. Use specific terms for better results.

## 6. Manual Pipeline Trigger
- **When to use:** Testing after config changes, generating ad-hoc reports, verifying system works after maintenance
- **How:** Navigate to /admin/trigger, click "Run Pipeline Now"
- **What happens:** Full pipeline runs (collect, classify, generate, email). Progress shown on page.
- **How long:** Typically 5-15 minutes depending on article volume

## 7. Troubleshooting

Use symptom-based format (from research):

**Symptom: No report email received this morning**
1. Check dashboard — did the pipeline run? (Last Run status)
2. If pipeline didn't run: Check Windows Task Scheduler (see Task Scheduler section below)
3. If pipeline ran but no email: Check recipient configuration (/admin/recipients)
4. Check logs: Open data/logs/ folder, find today's log file, search for "ERROR"
5. If Graph API error: Verify Azure AD credentials haven't expired (contact IT)

**Symptom: Pipeline ran but reports are empty**
1. Check source health on dashboard — are sources returning articles?
2. If sources show 0 articles: Source website may have changed. Disable source, contact developer.
3. If sources have articles but reports empty: Classification may have failed. Check logs for OpenAI errors.

**Symptom: Health alert email received**
1. Read alert — which source is flagged?
2. Navigate to /admin/sources, check source status
3. If source consistently low: Website may have changed structure. Disable and notify developer.
4. If temporary dip: Monitor next run, alert may resolve automatically

**Symptom: Drift alert email received**
1. This means AI classification patterns have changed
2. Usually not urgent — monitor for 2-3 days
3. If drift persists: Contact developer to review classification prompt

**Symptom: Task Scheduler task shows "Last Run Result: 0x1" (error)**
1. Open Task Scheduler: Start > search "Task Scheduler"
2. Navigate to MDInsights tasks
3. Check task history for error details
4. Common causes:
   - Python not found: Verify Python path in run_mdinsights.bat
   - .env missing or corrupt: Check C:\[project-path]\.env exists
   - Network error: Verify server can reach Azure and Apify APIs

## 8. Task Scheduler Reference
- Where to find: Start > search "Task Scheduler" > Task Scheduler Library
- Four MDInsights tasks: Pipeline, Backup, Drift Check, Monitor
- Checking task status: Right-click task > View History
- Manually running a task: Right-click task > Run
- Disabling temporarily: Right-click task > Disable (re-enable when ready)

## 9. Configuration Reference
