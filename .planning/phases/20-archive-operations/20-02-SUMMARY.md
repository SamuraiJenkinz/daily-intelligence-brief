## Decisions Made
- **Date-first navigation:** Archive displays dates as primary grouping with roles nested under each date (not role-first), matching natural mental model "what happened on this day"
- **Inline expanding players:** Clicking briefing row reveals player below it (not modal or new page), reducing navigation overhead
- **One-at-a-time playback:** JavaScript enforces single active audio element by pausing others before starting new playback
- **Estimated duration display:** Use file size / 16000 formula (assumes ~128kbps encoding) for initial duration estimate, replace with actual metadata when loaded
- **Custom control styling:** Implemented Marsh-branded play/pause button (circular, blue) and seek bar (light blue thumb) for brand consistency
