Build the OAuth2 client credentials token manager module, the api_events database model, and a standalone auth test command.

Purpose: This is the auth foundation that Phases 10-13 depend on. Factiva and Equity APIs use X-Api-Key only (no JWT needed), but they will also write events to api_events in their respective phases.

    Create `app/auth/token_manager.py` following the exact patterns from `app/services/emailer.py` (class structure, settings usage, retry decorator, httpx async client, structlog logging).

    **Structure:**
    ```python
    import time
    import enum
    import json
    from dataclasses import dataclass
    from datetime import datetime
    from typing import Optional

    import httpx
    import structlog
    from tenacity import retry, stop_after_attempt, wait_random_exponential, retry_if_exception_type, before_sleep_log

    from app.config import get_settings
    from app.database import SessionLocal
    from app.models.api_event import ApiEvent, ApiEventType
    ```

    **TokenInfo dataclass:**
    - `access_token: str`
    - `expires_at: float` (Unix timestamp)
    - `token_type: str = "Bearer"`

    **TokenManager class:**
    - `REFRESH_MARGIN_SECONDS = 300` (5-minute safety margin)
    - `__init__(self)`: Read settings via `get_settings()`. Store `_base_url`, `_client_id`, `_client_secret`, `_token_path`. Initialize `_token: Optional[TokenInfo] = None`. Create logger via `structlog.get_logger(__name__)`. If not configured, log warning (matching emailer.py pattern).
    - `is_configured(self) -> bool`: Return `get_settings().is_mmc_auth_configured()`.
    - `@property is_token_valid(self) -> bool`: Return True if `_token` is not None and `_token.expires_at > time.time() + self.REFRESH_MARGIN_SECONDS`.
    - `async def get_token(self) -> Optional[str]`: Main entry point. If token is valid, return `_token.access_token`. Otherwise call `_acquire_token()`. Return token string or None on failure. This is what consumers (Phase 12) will call.
    - `async def _acquire_token(self) -> Optional[str]`:
      - POST to `{base_url}{token_path}` with `Content-Type: application/x-www-form-urlencoded`, body: `grant_type=client_credentials&client_id={id}&client_secret={secret}`
      - Use `httpx.AsyncClient` with timeout=30.0
      - On success (200): parse JSON response, extract `access_token`, `expires_in`, `token_type`. Create `TokenInfo` with `expires_at = time.time() + expires_in`. Store in `_token`. Log `token_acquired` event (log expires_in and token_type, NEVER log the token value or secrets). Record ApiEvent with success=True. Return access_token.
      - On 401/403 (invalid credentials): Log error with status code. Record ApiEvent with success=False and detail containing status code and sanitized error. Do NOT retry (credentials won't magically become valid). Return None.
      - On 429 (rate limited): Log warning. Raise to trigger tenacity retry.
      - On 5xx (server error): Log warning. Raise to trigger tenacity retry.
      - On network error (httpx.TimeoutException, httpx.NetworkError): Raise to trigger tenacity retry.
      - Catch-all exception: Log error, record ApiEvent with success=False, return None.
    - Apply `@retry` decorator to `_acquire_token` matching emailer.py pattern: `stop=stop_after_attempt(3)`, `wait=wait_random_exponential(multiplier=1, min=2, max=10)`, `retry=retry_if_exception_type((httpx.TimeoutException, httpx.NetworkError, httpx.HTTPStatusError))`. Use `before_sleep_log(logger, logging.WARNING)`.
    - `def _record_event(self, event_type: ApiEventType, success: bool, detail: Optional[str] = None, run_id: Optional[int] = None)`: Create a new DB session, insert ApiEvent, commit, close. Wrap in try/except — never let event recording crash the token flow. Determine `api_name="auth"`.
    - `async def force_refresh(self) -> Optional[str]`: Invalidate current token (`_token = None`), call `_acquire_token()`. Log as `token_refreshed` or `token_refresh_failed`. Record appropriate ApiEvent. Used by the test command to verify refresh works.

    **Critical rules:**
    - NEVER log token values, client_id, or client_secret — only log event names, expiry durations, status codes, and error messages
    - Use `import logging` at top for `before_sleep_log` (matching emailer.py)
    - All event detail strings must be JSON-safe (use `json.dumps()` for complex details)
    - The `_record_event` method must handle its own DB session lifecycle (open, commit, close) independently of any caller's session
    - Determine whether to log as TOKEN_ACQUIRED vs TOKEN_REFRESHED based on whether `_token` was None before the call (first acquisition) or not (refresh)
