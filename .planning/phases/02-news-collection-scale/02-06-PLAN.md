  <files>app/services/collector.py</files>
  <action>
Modify `app/services/collector.py` to deduplicate articles before storing them in the database.

**Changes to `collect_from_sources()` method:**

Currently the method iterates over sources, scrapes each one, and stores articles immediately per-source. Change to a two-phase approach:

a. **Phase 1 - Collect all articles into memory:**
   Instead of calling `_store_articles()` inside the per-source loop, collect all articles into a single list:
   ```python
   all_articles = []

   for source in sources:
       try:
           articles = self._scrape_source(source)
           if articles:
               all_articles.extend(articles)
               self.logger.info("source_scraped", source_name=source.name, article_count=len(articles))
           else:
               self.logger.warning("no_articles_found", source_name=source.name)
       except Exception as e:
           self.logger.error("source_scrape_failed", source_name=source.name, error=str(e), exc_info=True)
           continue
   ```

b. **Phase 2 - Deduplicate:**
   After collecting from all sources, run deduplication:
   ```python
   from app.services.deduplicator import ArticleDeduplicator

   # Deduplicate across all sources
   pre_dedup_count = len(all_articles)
   if pre_dedup_count > 1:
       deduplicator = ArticleDeduplicator()
       all_articles = deduplicator.deduplicate(all_articles)
       self.logger.info(
           "deduplication_complete",
           articles_before=pre_dedup_count,
           articles_after=len(all_articles),
           duplicates_removed=pre_dedup_count - len(all_articles)
       )
   ```

c. **Phase 3 - Store:**
   Store all deduplicated articles in one batch:
   ```python
   if all_articles:
       self._store_articles(db, run.id, all_articles)
       total_articles = len(all_articles)
   ```

d. **Update Run record:**
   The existing `run.articles_collected = total_articles` now reflects deduplicated count. Add a log line showing both raw and deduplicated counts.

**Import `ArticleDeduplicator`** at top of file:
```python
from app.services.deduplicator import ArticleDeduplicator
```

**Do NOT change:**
- `__init__()` method
- `_scrape_source()` method
- `_get_source_scraper()` method (already updated in 02-03)
- `_store_articles()` method
- Error handling patterns (individual source failures still return empty list)

**Important:** The deduplicator uses lazy model loading, so the first run will be slower (model download). This is acceptable for a daily batch process. Log a message before deduplication: `self.logger.info("starting_deduplication", article_count=pre_dedup_count)`

Add a health check integration that runs AFTER collection completes:

2. **Add health check after collection in the pipeline endpoint:**
   After the collector finishes (and before or after classification), run a health check:
   ```python
   # Check source health after collection
   health_monitor = SourceHealthMonitor()
   db = SessionLocal()
   try:
       alerts = health_monitor.get_alerts(db)
       if alerts:
           logger.warning(
               "source_health_alerts",
               alert_count=len(alerts),
               sources=[a["source_name"] for a in alerts]
           )
   finally:
       db.close()
   ```

3. **Add a dedicated health check endpoint:**
   Create a new GET endpoint `/api/health/sources` that returns the full health report:
   ```python
   @router.get("/health/sources")
   async def check_source_health():
       """Check health of all enabled news sources."""
       health_monitor = SourceHealthMonitor()
       db = SessionLocal()
       try:
           results = health_monitor.check_all_sources(db)
           alerts = [r for r in results if r.get("alert")]
           return {
               "total_sources": len(results),
               "healthy": len([r for r in results if r["status"] == "healthy"]),
               "warning": len([r for r in results if r["status"] == "warning"]),
               "critical": len([r for r in results if r["status"] == "critical"]),
               "unknown": len([r for r in results if r["status"] == "unknown"]),
               "alerts": alerts,
               "sources": results
           }
       finally:
           db.close()
   ```

4. **Include health alerts in pipeline response:**
   If the pipeline endpoint returns a JSON response, add `health_alerts` field showing any source health concerns detected during this run.

**Do NOT change** the core pipeline flow (collect -> classify -> report). Health monitoring is additive -- if it fails, the pipeline should still complete. Wrap health check in try/except with a warning log on failure.
