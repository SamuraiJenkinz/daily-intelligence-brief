**Class design:**

```python
class SourceHealthMonitor:
    """Monitor source health by tracking article collection patterns."""

    def __init__(self, lookback_days: int = 7):
        self.lookback_days = lookback_days
        self.logger = structlog.get_logger().bind(service="health_monitor")
```

**Method 1: `check_source_health(db, source: Source) -> Dict`**

Check health of a single source:

a. Query article counts per completed run for this source over the last `lookback_days`:
   ```python
   from sqlalchemy import func
   from datetime import datetime, timedelta

   cutoff = datetime.utcnow() - timedelta(days=self.lookback_days)

   # Get per-run article counts for this source
   run_counts = (
       db.query(
           Run.id,
           Run.completed_at,
           func.count(NewsArticle.id).label('article_count')
       )
       .join(NewsArticle, NewsArticle.run_id == Run.id)
       .filter(
           NewsArticle.source_name == source.name,
           Run.completed_at >= cutoff,
           Run.status == RunStatus.COMPLETED
       )
       .group_by(Run.id, Run.completed_at)
       .order_by(Run.completed_at)
       .all()
   )
   ```

b. If no completed runs in lookback period, return `{"status": "unknown", "reason": "no_history", "alert": False, "source_name": source.name}`

c. Calculate baseline:
   - `baseline_avg = sum(counts) / len(counts)` (7-day moving average)
   - `baseline_min = min(counts)`

d. Check the MOST RECENT run's count:
   - Also check: has there been a completed run in the last 24 hours? Query:
     ```python
     last_24h = datetime.utcnow() - timedelta(hours=24)
     recent_run = (
         db.query(Run)
         .filter(Run.completed_at >= last_24h, Run.status == RunStatus.COMPLETED)
         .first()
     )
     ```
   - If no run in last 24h, that is itself an anomaly (but a pipeline-level one, not source-specific)

e. Return health dict based on rules:
   - **critical**: Latest run count == 0 AND baseline_avg > 0 -> `{"status": "critical", "reason": "zero_articles", "alert": True, ...}`
   - **warning**: Latest run count < baseline_avg * 0.5 -> `{"status": "warning", "reason": "below_baseline", "alert": True, ...}`
   - **healthy**: Latest run count >= baseline_avg * 0.5 -> `{"status": "healthy", "alert": False, ...}`

f. Always include in return dict: `source_name`, `status`, `reason` (if not healthy), `alert` (bool), `latest_count`, `baseline_avg`, `total_runs` (count of runs in lookback)

**Method 2: `check_all_sources(db) -> List[Dict]`**

Check health of ALL enabled sources:

a. Query all enabled sources: `db.query(Source).filter(Source.enabled == True).all()`
b. Call `check_source_health(db, source)` for each
c. Return list of health dicts
d. Log summary: total sources checked, alerts found

**Method 3: `get_alerts(db) -> List[Dict]`**

Convenience method returning only sources with `alert=True`:

a. Call `check_all_sources(db)`
b. Filter to only results where `alert == True`
c. Return filtered list

- Log info for healthy sources, warning for alerts
- Log full health report at info level in check_all_sources
