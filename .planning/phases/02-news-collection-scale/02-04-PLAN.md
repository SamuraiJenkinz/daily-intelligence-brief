2. **Create `app/services/deduplicator.py`:**

   Class: `ArticleDeduplicator`

   **Constructor:**
   ```python
   def __init__(self, model_name: str = "all-MiniLM-L6-v2", similarity_threshold: float = 0.85):
   ```
   - `model_name`: Pre-trained sentence transformer model. `all-MiniLM-L6-v2` is fast, small (80MB), and accurate enough for headline similarity. Do NOT use a larger model -- CPU performance matters for daily batch.
   - `similarity_threshold`: Default 0.85 per RESEARCH.md recommendation. Configurable for future tuning.
   - Load model lazily: store model_name and threshold in __init__, only call `SentenceTransformer(model_name)` on first `deduplicate()` call. Store in `self._model`. This avoids slow import on application startup.

   **deduplicate() method:**
   ```python
   def deduplicate(self, articles: List[Dict[str, Any]]) -> List[Dict[str, Any]]:
   ```

   Implementation:
   a. Early return if len(articles) <= 1
   b. Load model if not loaded: `self._model = SentenceTransformer(self.model_name)`
   c. Generate text for each article: `f"{article['title']} {article.get('description', '')}"`
   d. Encode all texts: `embeddings = self._model.encode(texts, convert_to_tensor=True)`
   e. Compute pairwise cosine similarity: `cos_scores = util.cos_sim(embeddings, embeddings)`
   f. Use Union-Find (disjoint set) algorithm to group duplicates:
      - For each pair (i, j) where i < j and cos_scores[i][j] >= threshold, union(i, j)
      - This correctly handles transitive duplicates (A similar to B, B similar to C -> all three are one group)
   g. For each group, pick the article with the EARLIEST `published_at` as the keeper
   h. Merge source_name from all articles in the group: join unique source names with ", "
   i. Keep the LONGEST description from the group (per RESEARCH.md recommendation)
   j. Return the deduplicated list

   **Union-Find helper** (can be a nested class or standalone functions inside the module):
   ```python
   class _UnionFind:
       def __init__(self, n):
           self.parent = list(range(n))
       def find(self, x):
           while self.parent[x] != x:
               self.parent[x] = self.parent[self.parent[x]]
               x = self.parent[x]
           return x
       def union(self, x, y):
           px, py = self.find(x), self.find(y)
           if px != py:
               self.parent[px] = py
   ```

   **Logging:**
   - Use structlog with `service="deduplicator"` binding
   - Log: total articles in, duplicates found, articles out
   - Log groups of 3+ articles at DEBUG level (useful for threshold tuning)

   **Important:** Handle the case where `published_at` is None in some articles (use `datetime.max` as sort fallback so articles with dates are preferred as keepers).

   **Do NOT import or use datasketch/MinHash.** The RESEARCH.md mentions it as an optimization, but for daily batches of ~500-2000 articles, direct cosine similarity is fast enough and simpler. MinHash adds complexity without meaningful benefit at this scale.
