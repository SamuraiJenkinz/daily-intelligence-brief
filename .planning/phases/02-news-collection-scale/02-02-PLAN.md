  <action>
Create `app/services/sources/rss_source.py` implementing a reusable RSS feed scraper.

The class must:

1. Extend `NewsSource` ABC from `app/services/sources/base.py`
2. Override `__init__` to accept `apify_client` (unused but required by ABC), `source_url` (the RSS feed URL), and an optional `source_name` parameter (since RSS feeds serve multiple sources with different display names)
3. Implement `scrape()` using `feedparser.parse(self.source_url)`

**scrape() implementation details:**

- Parse feed with `feedparser.parse(self.source_url)`
- Check `feed.bozo` flag. If True AND no entries, log warning and return empty list. If True but entries exist, log warning but CONTINUE processing (per RESEARCH.md: "Continue anyway if entries were extracted")
- Limit to first 20 entries: `feed.entries[:20]`
- For each entry, extract:
  - `title`: `entry.get('title', '').strip()` -- skip entry if empty
  - `description`: Try `entry.get('summary', '')` first, fall back to `entry.get('description', '')`, then strip HTML tags using a simple regex `re.sub(r'<[^>]+>', '', text)` since RSS descriptions often contain HTML
  - `url`: `entry.get('link', '').strip()`
  - `published_at`: Fall back through multiple date fields in order: `published_parsed`, `updated_parsed`, `created_parsed`. Convert time.struct_time to datetime: `datetime(*time_struct[:6])`. If no date field found, use `datetime.utcnow()` as fallback.
  - `source_name`: Use `self.source_name` if set in constructor, otherwise `feed.feed.get('title', 'RSS Feed')`

- Return list of article dicts matching standard schema
- Wrap entire method in try/except, return empty list on failure (matching error handling strategy)
- Use structlog with `source="rss"` and `url=self.source_url` bindings

**Constructor signature:**
```python
def __init__(self, apify_client, source_url: str, source_name: str = None):
    super().__init__(apify_client, source_url)
    self.source_name = source_name
```

This allows the collector to pass a specific display name when instantiating:
`RSSSource(self.apify_client, source.url, source_name=source.name)`
