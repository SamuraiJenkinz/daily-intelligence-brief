**Add import** at top of file: `from fastapi.responses import FileResponse` (FileResponse may already be imported in local scope for archive endpoint — move it to the top-level imports).

**New endpoint:**
```python
@router.get("/audio/{role}/{date}")
async def stream_audio(role: str, date: str):
```

**Implementation:**
1. SECURITY: Validate role against whitelist `["brokers", "leadership", "compliance", "underwriting"]`. Return 404 if invalid. Log warning with `audio_stream_invalid_role`.
2. SECURITY: Validate date format with `re.match(r'^\d{4}-\d{2}-\d{2}$', date)`. Return 404 if invalid. Log warning with `audio_stream_invalid_date`.
3. Build audio path: `audio_dir = Path(__file__).parent.parent.parent / "data" / "audio"`, then `audio_path = audio_dir / date / f"{role.lower()}.mp3"`
4. SECURITY: Path traversal prevention:
   - `resolved_path = audio_path.resolve()`
   - `resolved_audio_dir = audio_dir.resolve()`
   - Verify `str(resolved_path).startswith(str(resolved_audio_dir))` — if not, log warning with `audio_stream_path_traversal_attempt` and return 404
   - Verify `resolved_path.exists() and resolved_path.is_file()` — if not, return 404
5. Use try/except around path resolution. Re-raise HTTPException, catch all other exceptions and return 404.
6. Log `audio_stream_served` with role and date on success.
7. Return `FileResponse(path=str(resolved_path), media_type="audio/mpeg", filename=f"{role}_{date}.mp3")`

FileResponse automatically handles HTTP range requests (Accept-Ranges header, 206 Partial Content responses) which enables browser seeking in HTML5 audio player.

Place this endpoint BEFORE the existing `/admin/archive/{role}/{date}` endpoint to avoid route conflicts (FastAPI matches routes in order).
