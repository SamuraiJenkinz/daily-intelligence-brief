### Task 4: Integrate Collection with Database
**File**: `C:\BrasilIntel\MDInsights\app\services\collector.py` (modify)
**Action**: Modify

## Estimated Complexity
**Moderate** — Apify integration is straightforward using SDK, but CSS selectors for Reinsurance News require manual testing to ensure accuracy. Database integration is simple ORM operations. Testing requires actual Apify API calls (cost consideration).

## Notes
- **Apify cost consideration:** Web scraping consumes Apify credits. Use free tier for development (100 requests/month). Test with limit=10 to minimize costs during development.
- **CSS selector discovery:** Use browser DevTools on https://www.reinsurancene.ws/ to identify article containers, title selectors, description selectors, date selectors. Document in comments for maintainability.
- **Alternative if Apify blocks:** If Reinsurance News blocks Apify or has anti-bot protection, consider RSS feed fallback (research mentions RSS as alternative). Phase 2 will add RSS parser anyway.
- **Testing without Apify:** For offline testing, create mock ApifyCollector that returns hardcoded article list. Switch via environment flag.
- **Phase 2 preparation:** Base class pattern (NewsSource) enables easy addition of 18+ sources in Phase 2 without refactoring collector logic.
