## Estimated Complexity
**Moderate** — Azure OpenAI SDK integration is straightforward, structured outputs guarantee schema compliance (no parsing errors), but prompt engineering requires validation with test dataset. Classification accuracy depends on prompt quality — may need iteration based on results.

## Notes
- **Prompt iteration strategy:** If initial results show under-inclusion (too many single-role articles), strengthen "Be generous" instruction. If over-inclusion (every article gets all 4 roles), add "typical article: 1-3 roles, not all 4" guidance.
- **Cost optimization:** Azure OpenAI GPT-4o structured outputs cost ~$5/1M tokens input, ~$15/1M tokens output. Phase 1 with 20 articles ~0.5K tokens each = ~10K tokens input + ~5K tokens output = $0.10 per test run. Budget $5 for Phase 1 testing.
- **Multi-role validation:** Research target is 40-60% multi-role. If actual results significantly differ, investigate: Are articles genuinely single-role (narrow topics), or is prompt under-assigning roles?
- **Structured outputs guarantee:** Azure OpenAI structured outputs provide 100% schema compliance vs ~70-80% with JSON mode. No need for try/except JSON parsing — response.choices[0].message.parsed always matches ArticleClassification schema.
- **Temperature setting:** 0.3 balances consistency (lower = more deterministic) with classification quality. If results too generic, increase to 0.5. If too random, decrease to 0.1.
- **Phase 2 expansion:** Classification service is reusable for all 18+ sources. Phase 3 adds entity extraction and categorical tagging to same service.
