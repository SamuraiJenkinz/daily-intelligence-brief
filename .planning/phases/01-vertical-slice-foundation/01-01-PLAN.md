## Notes
- **Critical design decision:** Use JSON column for roles array instead of join table. SQLite JSON support is limited but sufficient for Phase 1 filtering in Python. Phase 2+ can add indexed boolean columns (has_brokers, has_leadership) for performance.
- **Reuse BrasilIntel patterns:** database.py, config.py, main.py structure is proven. Don't reinvent.
- **Testing approach:** After scaffolding, verify health check before moving to 01-02. This validates the foundation.
- **Reference:** BrasilIntel codebase at `C:\BrasilIntel\app\` for exact pattern implementation
