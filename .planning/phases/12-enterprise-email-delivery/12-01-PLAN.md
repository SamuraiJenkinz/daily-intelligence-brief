Create `app/services/enterprise_emailer.py` with class EnterpriseEmailClient. This MUST use async httpx (not sync) because `run_full_pipeline_with_email()` is async. Model on EquityPriceClient for structure but use httpx.AsyncClient like GraphEmailService.

Class structure:

```python
class EnterpriseEmailClient:
    """
    MMC Core API email client for MDInsights.

    Sends role-based HTML briefs via POST /coreapi/email/v1.
    Requires both JWT Bearer token and X-Api-Key authentication.
    Falls back to GraphEmailService when unavailable (handled by pipeline, not this client).
    """
```

**__init__(self):**
- Read from get_settings(): base_url (mmc_api_base_url), api_key (mmc_api_key), sender_email (mmc_sender_email), sender_name (mmc_sender_name), email_path (mmc_email_path)
- Create structlog logger bound to service="enterprise_emailer"

**is_configured(self) -> bool:**
- Return True if base_url AND api_key AND sender_email are all truthy
- This is a quick check — callers use it before attempting send

**_build_headers(self, token: str) -> Dict[str, str]:**
- Return {"Authorization": f"Bearer {token}", "X-Api-Key": self.api_key, "Content-Type": "application/json", "Accept": "application/json"}
- IMPORTANT: token is the JWT string, NOT the settings — never store token on self

**_build_payload(self, to_addresses, subject, html_body, cc_addresses) -> Dict[str, Any]:**
- Build the POST JSON body
- IMPORTANT: Field names are INFERRED and must be validated on deployment machine
- Use named constants for field names so they can be corrected in one place:
  ```python
  # Payload field names — INFERRED, validate against real API on deployment
  FIELD_SUBJECT = "subject"
  FIELD_HTML_BODY = "htmlBody"
  FIELD_TO_RECIPIENTS = "toRecipients"
  FIELD_CC_RECIPIENTS = "ccRecipients"
  FIELD_SENDER = "impersonatedEmail"
  FIELD_SENDER_NAME = "senderName"
  ```
  Define these as class-level constants.
- Payload structure:
  ```python
  payload = {
      self.FIELD_SUBJECT: subject,
      self.FIELD_HTML_BODY: html_body,
      self.FIELD_TO_RECIPIENTS: to_addresses,
      self.FIELD_SENDER: self.sender_email,
  }
  if self.sender_name:
      payload[self.FIELD_SENDER_NAME] = self.sender_name
  if cc_addresses:
      payload[self.FIELD_CC_RECIPIENTS] = cc_addresses
  ```
- Log the payload structure (field names only, NOT the html_body content) at DEBUG level on first call

**_post_email(self, token, payload) -> httpx.Response:**
- Async method with tenacity retry decorator:
  ```python
  @retry(
      stop=stop_after_attempt(2),
      wait=wait_random_exponential(multiplier=1, min=2, max=10),
      retry=retry_if_exception_type((httpx.TimeoutException, httpx.ConnectError)),
  )
  ```
- Build URL: f"{self.base_url}{self.email_path}"
- Use httpx.AsyncClient(timeout=30.0) — MUST be async
- Return the raw response object

**send_email(self, token, to_addresses, subject, html_body, cc_addresses=None, run_id=None) -> Dict[str, Any]:**
- Async method — the main public API
- Guard: if not to_addresses: return {"status": "error", "message": "No recipients specified"}
- Build payload via _build_payload()
- Log html_body length at INFO: self.logger.info("enterprise_email_sending", recipient_count=len(to_addresses), subject=subject, html_body_length=len(html_body))
- Try _post_email(token, payload)
- Response handling:
  - 200/201/202: Log success, _record_event(EMAIL_SENT, True, ...), return {"status": "ok", "recipients": len(to_addresses)}
  - 401/403: Log error with hint "Check JWT token validity and X-Api-Key". _record_event(EMAIL_FALLBACK, False, ...). Return {"status": "auth_error", "message": error_msg}. Do NOT retry — auth errors don't resolve via retry. This is critical.
  - 5xx: Raise httpx.NetworkError to trigger tenacity retry on _post_email. If retries exhausted, the except block catches it.
  - Other 4xx: Log error, _record_event(EMAIL_FALLBACK, False, ...), return {"status": "error", "message": error_msg}
- Catch (httpx.TimeoutException, httpx.ConnectError, httpx.NetworkError): log warning, _record_event(EMAIL_FALLBACK, False), return {"status": "error", "message": error_msg}
- Catch Exception (broad): log error, _record_event(EMAIL_FALLBACK, False), return {"status": "error", "message": error_msg}
- NEVER raise exceptions to callers — always return a result dict

**_record_event(self, event_type, success, detail=None, run_id=None):**
- IDENTICAL pattern to EquityPriceClient._record_event()
- Open own SessionLocal(), create ApiEvent(event_type=event_type, api_name="email", timestamp=datetime.utcnow(), success=success, detail=detail[:500] if detail else None, run_id=run_id)
- Commit. On any exception: log warning, swallow — event recording NEVER crashes delivery.
