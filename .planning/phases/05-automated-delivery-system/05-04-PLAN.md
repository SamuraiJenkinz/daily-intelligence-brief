**deploy/run_mdinsights.bat** -- modeled on BrasilIntel's `C:\BrasilIntel\deploy\run_brasilintel.bat`:

1. **Set working directory** to project root (one level up from deploy/):
   ```batch
   @echo off
   SET SCRIPT_DIR=%~dp0
   cd /d "%SCRIPT_DIR%\.."
   ```

2. **Generate timestamp** for log file naming:
   ```batch
   for /f "tokens=2-4 delims=/ " %%a in ('date /t') do (set mydate=%%c-%%a-%%b)
   for /f "tokens=1-2 delims=/: " %%a in ('time /t') do (set mytime=%%a%%b)
   set timestamp=%mydate%_%mytime%
   ```

3. **Create log directory** if it doesn't exist:
   ```batch
   if not exist "data\logs" mkdir "data\logs"
   ```

4. **Activate virtual environment**:
   ```batch
   call venv\Scripts\activate.bat
   ```

5. **Run MDInsights pipeline** with output to log file:
   ```batch
   echo ============================================== >> "data\logs\mdinsights_%mydate%.log"
   echo MDInsights Pipeline Run: %timestamp% >> "data\logs\mdinsights_%mydate%.log"
   echo ============================================== >> "data\logs\mdinsights_%mydate%.log"
   python -m app.main run-pipeline >> "data\logs\mdinsights_%mydate%.log" 2>&1
   ```

6. **Capture exit code** and log result:
   ```batch
   set exitcode=%errorlevel%
   echo Exit code: %exitcode% >> "data\logs\mdinsights_%mydate%.log"
   echo. >> "data\logs\mdinsights_%mydate%.log"
   ```

7. **Exit with same code** (Task Scheduler uses exit code for success/failure detection):
   ```batch
   exit /b %exitcode%
   ```

Also create `data/logs/.gitkeep` to ensure the logs directory is tracked but log files are not.

**deploy/setup_task.ps1** -- PowerShell script that creates the Windows Task Scheduler task:

1. **Header and parameters**:
   ```powershell
   <#
   .SYNOPSIS
       Creates Windows Task Scheduler task for MDInsights daily pipeline.
   .DESCRIPTION
       Registers a scheduled task that runs the MDInsights pipeline daily at 06:00.
       Also registers a secondary monitoring task that runs at 09:00 to verify
       the pipeline completed successfully (detects scheduler-level failures).
   .PARAMETER TaskName
       Name of the scheduled task (default: "MDInsights Daily Pipeline")
   .PARAMETER TriggerTime
       Time to run daily (default: "06:00")
   .PARAMETER MonitorTime
       Time to run monitoring check (default: "09:00")
   .PARAMETER ProjectPath
       Path to MDInsights project root (default: auto-detect from script location)
   .EXAMPLE
       .\setup_task.ps1
       .\setup_task.ps1 -TriggerTime "05:30"
       .\setup_task.ps1 -TaskName "MDInsights Test" -TriggerTime "14:00"
   #>
   param(
       [string]$TaskName = "MDInsights Daily Pipeline",
       [string]$TriggerTime = "06:00",
       [string]$MonitorTime = "09:00",
       [string]$ProjectPath = ""
   )
   ```

2. **Auto-detect project path** from script location:
   ```powershell
   if (-not $ProjectPath) {
       $ProjectPath = Split-Path -Parent (Split-Path -Parent $MyInvocation.MyCommand.Path)
   }
   ```

3. **Validate project structure**:
   - Check `deploy\run_mdinsights.bat` exists
   - Check `venv\Scripts\activate.bat` exists
   - Check `app\main.py` exists

4. **Create the main pipeline task**:
   ```powershell
   $Action = New-ScheduledTaskAction `
       -Execute "cmd.exe" `
       -Argument "/c `"$ProjectPath\deploy\run_mdinsights.bat`"" `
       -WorkingDirectory $ProjectPath

   $Trigger = New-ScheduledTaskTrigger -Daily -At $TriggerTime

   $Settings = New-ScheduledTaskSettingsSet `
       -AllowStartIfOnBatteries `
       -DontStopIfGoingOnBatteries `
       -StartWhenAvailable `
       -RunOnlyIfNetworkAvailable `
       -ExecutionTimeLimit (New-TimeSpan -Hours 2) `
       -RestartCount 2 `
       -RestartInterval (New-TimeSpan -Minutes 10)

   $Principal = New-ScheduledTaskPrincipal `
       -UserId "SYSTEM" `
       -LogonType ServiceAccount `
       -RunLevel Highest
   ```

5. **Create the monitoring task** (runs at 09:00 to verify pipeline ran):
   ```powershell
   $MonitorAction = New-ScheduledTaskAction `
       -Execute "cmd.exe" `
       -Argument "/c `"$ProjectPath\venv\Scripts\python.exe`" `"$ProjectPath\deploy\check_last_run.py`"" `
       -WorkingDirectory $ProjectPath

   $MonitorTrigger = New-ScheduledTaskTrigger -Daily -At $MonitorTime

   $MonitorSettings = New-ScheduledTaskSettingsSet `
       -AllowStartIfOnBatteries `
       -DontStopIfGoingOnBatteries `
       -StartWhenAvailable `
       -ExecutionTimeLimit (New-TimeSpan -Minutes 5)
   ```

6. **Register both tasks** (update if they exist):
   Register the pipeline task with $TaskName.
   Register the monitoring task with "$TaskName - Monitor".

7. **Output confirmation** with task details:
   - Task name, trigger time, monitor time
   - Project path, batch script path, log directory path
   - How to test: `schtasks /run /tn "MDInsights Daily Pipeline"`
   - How to check: `schtasks /query /tn "MDInsights Daily Pipeline" /v`

Key Task Scheduler settings for main task:
- "Run whether user is logged on or not" (via SYSTEM principal)
- "Run with highest privileges" (RunLevel Highest)
- Start when available (catches up if machine was off at 06:00)
- Network required (needs internet for Apify, Azure OpenAI, Graph API)
- 2-hour execution time limit
- 2 restart attempts with 10-minute interval on failure
- Allow on battery (for laptop development)

Create `deploy/check_last_run.py` -- a standalone Python script that checks whether the pipeline ran successfully today. This catches scheduler-level failures (batch script crash before Python starts, Task Scheduler error, machine offline at 06:00).

The script:

1. **Checks the database** for a completed Run record from today:
   ```python
   # Query the most recent Run
   # If no Run exists with today's date, or latest Run has status FAILED, alert
   ```

2. **Checks for today's log file** at `data/logs/mdinsights_{date}.log`:
   - If log file missing entirely: scheduler never ran the batch script
   - If log file exists but has no "Exit code: 0": pipeline ran but failed

3. **Checks for today's archived reports** at `data/reports/{role}/{date}.html`:
   - If report files missing: email generation failed

4. **Sends alert email** if any check fails:
   ```python
   import asyncio
   import sys
   import os
   from datetime import datetime, date

   # Add project root to path
   sys.path.insert(0, os.path.dirname(os.path.dirname(os.path.abspath(__file__))))

   from app.database import SessionLocal
   from app.models import Run, RunStatus
   from app.services.emailer import GraphEmailService
   from app.config import get_settings

   def check_last_run():
       """Check if today's pipeline run completed successfully."""
       settings = get_settings()
       today = date.today()
       today_str = today.strftime("%Y-%m-%d")
       issues = []

       # Check 1: Database run record
       db = SessionLocal()
       try:
           latest_run = db.query(Run).order_by(Run.id.desc()).first()
           if latest_run is None:
               issues.append("No pipeline runs found in database")
           elif latest_run.started_at.date() != today:
               issues.append(f"Latest run is from {latest_run.started_at.date()}, not today ({today})")
           elif latest_run.status != RunStatus.COMPLETED:
               issues.append(f"Latest run status: {latest_run.status.value} (expected: completed)")
       finally:
           db.close()

       # Check 2: Log file exists
       # (date format in batch script may vary, check for today's date pattern)
       log_dir = "data/logs"
       if os.path.isdir(log_dir):
           today_logs = [f for f in os.listdir(log_dir) if today_str.replace("-", "") in f or today_str in f]
           if not today_logs:
               issues.append(f"No log file found for {today_str} in {log_dir}/")
       else:
           issues.append(f"Log directory {log_dir}/ does not exist")

       # Check 3: Archived reports exist
       roles = ["brokers", "leadership", "compliance", "underwriting"]
       for role in roles:
           report_path = f"data/reports/{role}/{today_str}.html"
           if not os.path.isfile(report_path):
               issues.append(f"Missing report: {report_path}")
               break  # One missing report is enough to flag

       return issues

   async def send_alert(issues):
       """Send alert email listing issues."""
       settings = get_settings()
       if not settings.admin_email:
           print("No admin_email configured, cannot send alert")
           return

       email_service = GraphEmailService()
       subject = f"[MDInsights] Pipeline Monitor Alert - {date.today().strftime('%d %B %Y')}"
       issues_html = "".join(f"<li>{issue}</li>" for issue in issues)
       html_body = f"""
       <h2>MDInsights Pipeline Monitor Alert</h2>
       <p>The daily pipeline monitoring check detected the following issues:</p>
       <ul>{issues_html}</ul>
       <p>Please investigate. This may indicate the scheduled task failed to run,
       the batch script crashed, or the machine was offline.</p>
       <p><small>Sent by deploy/check_last_run.py at {datetime.utcnow().strftime('%H:%M UTC')}</small></p>
       """
       await email_service.send_email(
           to_addresses=[settings.admin_email],
           subject=subject,
           html_body=html_body
       )

   if __name__ == "__main__":
       issues = check_last_run()
       if issues:
           print(f"ALERT: {len(issues)} issue(s) detected:")
           for issue in issues:
               print(f"  - {issue}")
           asyncio.run(send_alert(issues))
           sys.exit(1)
       else:
           print("OK: Pipeline ran successfully today")
           sys.exit(0)
   ```

Key design decisions:
- Script is standalone (adds project root to sys.path) so it can run from Task Scheduler
- Checks three independent signals: database, log file, archived reports
- Uses same GraphEmailService for alerting (consistent with pipeline)
- Exit code 1 = issues found, 0 = OK (Task Scheduler tracks this too)
- Runs at 09:00 (3 hours after 06:00 pipeline, allowing plenty of execution time)
