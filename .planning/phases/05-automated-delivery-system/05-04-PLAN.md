  <action>
Create `deploy/setup_task.ps1` that creates a Windows Task Scheduler task for daily MDInsights execution.

The PowerShell script must:

1. **Header and parameters**:
   ```powershell
   <#
   .SYNOPSIS
       Creates Windows Task Scheduler task for MDInsights daily pipeline.
   .DESCRIPTION
       Registers a scheduled task that runs the MDInsights pipeline daily at 06:00.
       The task executes deploy\run_mdinsights.bat which handles venv activation,
       pipeline execution, logging, and exit code reporting.
   .PARAMETER TaskName
       Name of the scheduled task (default: "MDInsights Daily Pipeline")
   .PARAMETER TriggerTime
       Time to run daily (default: "06:00")
   .PARAMETER ProjectPath
       Path to MDInsights project root (default: auto-detect from script location)
   .EXAMPLE
       .\setup_task.ps1
       .\setup_task.ps1 -TriggerTime "05:30"
       .\setup_task.ps1 -TaskName "MDInsights Test" -TriggerTime "14:00"
   #>
   param(
       [string]$TaskName = "MDInsights Daily Pipeline",
       [string]$TriggerTime = "06:00",
       [string]$ProjectPath = ""
   )
   ```

2. **Auto-detect project path** from script location:
   ```powershell
   if (-not $ProjectPath) {
       $ProjectPath = Split-Path -Parent (Split-Path -Parent $MyInvocation.MyCommand.Path)
   }
   ```

3. **Validate project structure**:
   - Check `deploy\run_mdinsights.bat` exists
   - Check `venv\Scripts\activate.bat` exists
   - Check `app\main.py` exists

4. **Create the scheduled task**:
   ```powershell
   $Action = New-ScheduledTaskAction `
       -Execute "cmd.exe" `
       -Argument "/c `"$ProjectPath\deploy\run_mdinsights.bat`"" `
       -WorkingDirectory $ProjectPath

   $Trigger = New-ScheduledTaskTrigger -Daily -At $TriggerTime

   $Settings = New-ScheduledTaskSettingsSet `
       -AllowStartIfOnBatteries `
       -DontStopIfGoingOnBatteries `
       -StartWhenAvailable `
       -RunOnlyIfNetworkAvailable `
       -ExecutionTimeLimit (New-TimeSpan -Hours 2) `
       -RestartCount 2 `
       -RestartInterval (New-TimeSpan -Minutes 10)

   $Principal = New-ScheduledTaskPrincipal `
       -UserId "SYSTEM" `
       -LogonType ServiceAccount `
       -RunLevel Highest
   ```

5. **Register task** (update if exists):
   ```powershell
   $existingTask = Get-ScheduledTask -TaskName $TaskName -ErrorAction SilentlyContinue
   if ($existingTask) {
       Set-ScheduledTask -TaskName $TaskName -Action $Action -Trigger $Trigger -Settings $Settings -Principal $Principal
       Write-Host "Updated existing task: $TaskName"
   } else {
       Register-ScheduledTask -TaskName $TaskName -Action $Action -Trigger $Trigger -Settings $Settings -Principal $Principal
       Write-Host "Created new task: $TaskName"
   }
   ```

6. **Output confirmation** with task details:
   - Task name
   - Trigger time
   - Project path
   - Batch script path
   - Log directory path
   - How to test: `schtasks /run /tn "MDInsights Daily Pipeline"`
   - How to check: `schtasks /query /tn "MDInsights Daily Pipeline" /v`

Key Task Scheduler settings:
- "Run whether user is logged on or not" (via SYSTEM principal)
- "Run with highest privileges" (RunLevel Highest)
- Start when available (catches up if machine was off at 06:00)
- Network required (needs internet for Apify, Azure OpenAI, Graph API)
- 2-hour execution time limit (generous for collection + classification + email)
- 2 restart attempts with 10-minute interval on failure
- Allow on battery (for laptop development)
