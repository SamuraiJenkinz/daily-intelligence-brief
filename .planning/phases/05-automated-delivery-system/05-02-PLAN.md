  <action>
Create `app/templates/email/` directory and `role_email.html` using ONLY table-based layout. NO JavaScript, NO CSS Grid, NO Flexbox. The template must work when rendered by premailer's `transform()` for CSS inlining.

The template receives these Jinja2 context variables (matching the reporter's render call):
- `role` (str): "Brokers", "Leadership", "Compliance", or "Underwriting"
- `articles` (list[dict]): Already filtered for this role, priority-sorted. Each has: title, description, summary, source_url, source_name, published_at, priority, sentiment, impact_level, category, region, business_line, entities (list of dicts with name/type/context)
- `executive_summary` (dict): Has summary_paragraphs (list[str]), key_numbers (list[str]), role_context (str)
- `report_date` (datetime)
- `company_name` (str): "Marsh"
- `edition_stats` (dict): source_count, article_count, entity_count, signal_count
- `sector_heatmap` (list[dict]): Each has sector, signal, signal_class, article_count
- `entity_tracker` (list[dict]): Each has name, count, type
- `market_pulse` (list[dict]): Each has label, value, status_class, dot_class
- `what_to_watch` (dict): Has items (list of dicts with title, description, timeframe, impact_roles)

Template structure (all `<table role="presentation">` with inline styles):

1. **Outer wrapper**: Full-width table, centered 600px inner table, background #f5f7fa
2. **CONFIDENTIAL banner**: Red/dark bar at top with "CONFIDENTIAL - Internal Use Only"
3. **Header section**: Marsh dark blue (#00263e) background
   - "Marsh Intelligence Brief" title (font-weight: 300)
   - Role name bold (font-weight: 600)
   - Date formatted as "07 February 2026"
   - "Curated by Kevin Taylor | Colleague Technology Services" attribution
4. **Market Pulse bar**: Compact horizontal display of sector indicators
   - Use background colors: green (#28a745) for Strong, blue (#0077c8) for Stable, amber (#fd7e14) for Mixed, red (#dc3545) for Softening
   - Each indicator: label + colored dot + value text
   - Wrap in single-row table cells
5. **Executive Summary section**: White card with blue-left border (#00a3e0, 4px)
   - "Executive Summary" heading
   - Summary paragraphs from executive_summary.summary_paragraphs
   - Key numbers as bullet list if present
   - Role context as italic closing line
6. **Articles section**: One card per article with priority color left-border
   - Priority colors: Critical=#dc3545, High=#fd7e14, Medium=#ffc107, Monitor=#6c757d
   - Article title as link (color #00263e, no underline)
   - Summary text (font-size 13px, color #555)
   - Chips row: sentiment chip, impact_level chip, region chip, business_line chip
   - Source name + date footer line
   - Use `{% for article in articles %}` loop
7. **Sector Heatmap section**: "Sector Activity" heading
   - Table with rows per sector: sector name | signal text | article count
   - Color-code signal text: heat-positive=#28a745, heat-negative=#dc3545, heat-neutral=#fd7e14
8. **Entity Tracker section**: "Key Entities" heading
   - Table with top 10 entities: rank | entity name | mention count | type
9. **What to Watch section**: "What to Watch" heading
   - Cards for each item: title, description, timeframe badge, impact_roles list
   - Only render if what_to_watch.items is not empty
10. **Footer section**: Light gray background
    - "Curated by Kevin Taylor | Colleague Technology Services"
    - Edition stats: "X articles from Y sources | Z entities tracked | W signals"
    - "CONFIDENTIAL - For internal use only"
    - "This is an automated intelligence brief."

CSS approach:
- Put a `<style>` block in `<head>` with @media queries for mobile responsiveness (premailer preserves these)
- All critical styles ALSO as inline `style=""` attributes (premailer will inline from style block too, but explicit is safer)
- @media query: `@media only screen and (max-width: 600px)` to make stacked layout, 100% width
- Use MSO conditional `<!--[if mso]>` only if needed for Outlook table width fixes
- Max-width 600px for all content tables
- Font stack: `-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`
- Line-height: 1.6 for body text, 1.2 for headings

Chip styling (inline for each chip span within a table cell):
- Inline-block, padding 2px 8px, border-radius 3px, font-size 11px, margin-right 4px
- Sentiment: positive=#d4edda text #155724, negative=#f8d7da text #721c24, neutral=#e2e3e5 text #383d41
- Impact: High=#fff3cd text #856404, Moderate=#d1ecf1 text #0c5460, Low=#e2e3e5 text #383d41
- Other chips: light gray background #e9ecef, text #495057

IMPORTANT constraints:
- ZERO JavaScript anywhere in the template
- NO CSS Grid or Flexbox (Outlook uses Word rendering engine)
- NO external images/stylesheets (blocked by email clients)
- NO shorthand CSS (write margin-top/margin-bottom separately, not margin shorthand)
- Keep total HTML under 100KB to avoid Gmail clipping
- Use `role="presentation"` on all layout tables for accessibility
