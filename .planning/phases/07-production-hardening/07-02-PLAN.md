2. Create `app/services/backup_manager.py` with class `DatabaseBackupManager`:

   **Constructor:** Takes `connection_string: str`, `container: str`, `retention_days: int`. Stores a structlog logger bound with `service="backup"`. Creates `BlobServiceClient.from_connection_string(connection_string)`. Handle the case where connection_string is empty gracefully (log warning, set blob_service to None).

   **Method `backup_database(db_path: str) -> dict`:**
   - Create `data/backups/` directory if not exists
   - Generate timestamped filename: `mdinsights_{YYYYMMDD_HHMMSS}.db`
   - Use `sqlite3.connect(db_path)` as source, `sqlite3.connect(local_backup_path)` as dest
   - Call `src_conn.backup(dst_conn)` (this is safe with concurrent readers)
   - Close both connections
   - Call `_verify_backup(local_backup_path)` - raises ValueError if integrity check fails
   - If Azure storage configured, call `_upload_to_azure(local_backup_path, backup_filename)`
   - If Azure not configured, log info that backup is local-only
   - Call `_cleanup_local_backups()` to remove local backups older than 7 days
   - If Azure configured, call `_cleanup_azure_backups()` for retention
   - Return result dict: `{"status": "ok", "local_path": ..., "azure_uploaded": bool, "backup_name": ...}`
   - Wrap in try/except, log errors, re-raise

   **Method `_verify_backup(backup_path: str)`:**
   - Connect to backup, execute `PRAGMA integrity_check`
   - If result != "ok", raise ValueError
   - Also check table count: `SELECT count(*) FROM sqlite_master WHERE type='table'` - if 0, raise ValueError (empty backup)
   - Log verification success

   **Method `_upload_to_azure(local_path: str, blob_name: str)`:**
   - Get blob client from service
   - Upload with `overwrite=False` (prevent accidental overwrite)
   - Log upload success with blob name and container

   **Method `_cleanup_local_backups(max_age_days: int = 7)`:**
   - List files in `data/backups/` matching `mdinsights_*.db`
   - Delete files older than `max_age_days` based on file mtime
   - Log count of deleted files

   **Method `_cleanup_azure_backups()`:**
   - List blobs in container
   - Delete blobs older than `self.retention_days` based on `last_modified`
   - Log count of deleted blobs
   - Handle case where container doesn't exist (create it)

   IMPORTANT: `azure-storage-blob` is already installed (v12.23.1) per research. Do NOT add to requirements.txt. It is a transitive dependency of azure-identity.
