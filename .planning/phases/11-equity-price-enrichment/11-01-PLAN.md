Create `app/collectors/equity.py` with class EquityPriceClient modeled EXACTLY on FactivaCollector:
- BASE_PRICE_PATH = "/coreapi/equity-price/v1/price" (configurable — exact path unknown)
- __init__: reads base_url, api_key from get_settings(), creates structlog logger bound to service="equity_price_client"
- is_configured(): returns bool(self.base_url and self.api_key) — same as FactivaCollector
- _build_headers(): returns {"X-Api-Key": self.api_key, "Accept": "application/json"} — identical to FactivaCollector
- get_price(ticker: str, exchange: str = "NYSE", run_id: Optional[int] = None) -> Optional[Dict[str, Any]]:
  - Calls GET {base_url}{BASE_PRICE_PATH} with params {"ticker": ticker, "exchange": exchange}
  - Uses @retry(stop=stop_after_attempt(2), wait=wait_exponential(1, min=2, max=10), retry=retry_if_exception_type((httpx.TimeoutException, httpx.ConnectError)))
  - On success: parse response JSON, extract price data with multiple field name fallbacks:
    - price: response.get("price") or response.get("lastPrice") or response.get("last")
    - change: response.get("change") or response.get("priceChange") or response.get("netChange")
    - change_pct: response.get("changePct") or response.get("percentChange") or response.get("pctChange")
  - Record ApiEvent(EQUITY_FETCH, success=True, detail=json.dumps({"ticker": ticker, "price": price}), run_id=run_id)
  - Return {"ticker": ticker, "exchange": exchange, "price": price, "change": change, "change_pct": change_pct}
  - On ANY exception: log warning, record ApiEvent(EQUITY_FETCH, success=False, detail=error info), return None
  - On 4xx HTTP status: log warning, return None (do NOT raise — same as FactivaCollector._fetch_article 4xx handling)
- _record_event(): IDENTICAL pattern to FactivaCollector._record_event — isolated SessionLocal, swallow errors, api_name="equity"
