  <action>
In `app/templates/role_brief.html`, add equity chip rendering inside each article card. The equity data should appear in the impact-strip div (the chip row at the bottom of each article card, around line 755-771).

Add the following Jinja2 block BEFORE the existing sentiment/impact/region/entity chips in the impact-strip div (so equity chips appear first — most visually prominent position):

```html
{% if article.equity_data %}
{% for eq in article.equity_data %}
<span class="equity-chip" style="display: inline-flex; align-items: center; padding: 3px 10px; border-radius: 4px; font-size: 0.75em; margin-right: 6px; margin-bottom: 4px; font-weight: 600; background-color: #f8f9fa; border: 1px solid #dee2e6;">
    <span style="color: #00263e; margin-right: 6px;">{{ eq.ticker }}</span>
    {% if eq.price is not none %}
    <span style="color: #495057;">${{ "%.2f"|format(eq.price) }}</span>
    {% endif %}
    {% if eq.change is not none and eq.change_pct is not none %}
    {% if eq.change > 0 %}
    <span style="color: #198754; margin-left: 6px;">+{{ "%.2f"|format(eq.change) }} (+{{ "%.2f"|format(eq.change_pct) }}%)</span>
    {% elif eq.change < 0 %}
    <span style="color: #dc3545; margin-left: 6px;">{{ "%.2f"|format(eq.change) }} ({{ "%.2f"|format(eq.change_pct) }}%)</span>
    {% else %}
    <span style="color: #6c757d; margin-left: 6px;">0.00 (0.00%)</span>
    {% endif %}
    {% endif %}
</span>
{% endfor %}
{% endif %}
```

Also add a small CSS rule in the template's style block for the equity-chip hover effect:
```css
.equity-chip {
    transition: box-shadow 0.15s;
}
.equity-chip:hover {
    box-shadow: 0 1px 4px rgba(0,0,0,0.12);
}
```

Placement: Insert the equity chip block inside the `<div class="impact-strip">` element, BEFORE the `{% if article.sentiment %}` block. This puts equity data first in the chip row.

IMPORTANT: The equity_data is a list — an article may mention multiple tracked companies. The for loop handles this. If equity_data is empty (unmapped entities, failed lookups, unconfigured API), the entire block is skipped via the outer {% if %}.

CRITICAL: Use `is not none` (Jinja2 comparison) NOT `!= None`. Jinja2 does not support `is not None` with capital N — use lowercase `none`.
