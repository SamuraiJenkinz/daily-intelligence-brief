  <action>
1. Add archive routes to `app/routers/admin.py`:

   GET /admin/archive -> Archive browser page
   - Scan `data/reports/` directory structure. The archive layout is: `data/reports/{role_lower}/{YYYY-MM-DD}.html`
     - Roles: brokers, leadership, compliance, underwriting (lowercase directory names)
   - Build archive data structure: list of dicts with {date, reports: {role: {path, size_kb, exists}}}
     - Iterate each role directory, collect all date-named .html files
     - Group by date (descending), for each date show which roles have reports
   - Accept optional query params: role (str, filter to one role), month (str, format YYYY-MM)
   - If HX-Request header present, return archive_list.html partial; otherwise return full archive.html page
   - Handle case where data/reports/ directory does not exist (show "No reports yet" message)

   GET /admin/archive/{role}/{date} -> Serve archived report HTML
   - SECURITY: Validate date matches YYYY-MM-DD regex pattern
   - SECURITY: Validate role is one of: brokers, leadership, compliance, underwriting (lowercase)
   - SECURITY: Use Path.resolve() and verify resolved path starts within data/reports/ directory
   - If file not found, return 404 with user-friendly message
   - Return FileResponse with media_type="text/html"

2. Create `app/templates/admin/archive.html` (extends base.html):
   - Set active_nav to "archive"
   - Title: "Report Archive"
   - Filter row:
     - Role dropdown (All Roles, Brokers, Leadership, Compliance, Underwriting) with hx-get="/admin/archive" hx-trigger="change" hx-target="#archive-list" hx-include="[name='month']"
     - Month dropdown (populated from available months) with same HTMX pattern
   - Archive listing area with id="archive-list": include archive_list.html partial

3. Create `app/templates/admin/partials/archive_list.html`:
   - Group reports by date, most recent first
   - For each date: Bootstrap card with date header (formatted nicely, e.g., "Friday, 7 February 2026")
   - Inside each date card: grid of role badges/buttons
     - Each role that has a report: clickable badge/link that opens /admin/archive/{role}/{date} in new tab (target="_blank")
     - Show file size in KB next to each role
     - Roles without reports for that date shown as muted/disabled
   - If no reports exist: show a centered message "No reports archived yet. Run the pipeline to generate reports."
   - Pagination: Show last 30 days by default, "Load more" button with HTMX to fetch older dates
