<task type="auto">
  <name>Task 1: Create recipient management routes</name>
  <files>app/routers/admin.py</files>
  <action>
Add recipient management routes to `app/routers/admin.py`:

1. GET /admin/recipients -> Recipient management page
   - Load current recipients for all four roles using get_settings().get_email_recipients(role)
   - Build recipients dict: {role_name: EmailRecipients(to, cc, bcc)} for each of: Brokers, Leadership, Compliance, Underwriting
   - If HX-Request, return partial; otherwise return full recipients.html page
   - Pass recipients dict and roles list to template

2. GET /admin/recipients/{role}/edit -> Return edit form partial for one role
   - Validate role is one of: Brokers, Leadership, Compliance, Underwriting
   - Load current recipients for that role
   - Return recipient_card.html partial in edit mode (pass edit=True)

3. POST /admin/recipients/{role} -> Save updated recipients for a role
   - Accept Form parameters: to (str), cc (str), bcc (str) -- comma-separated email addresses
   - Validate role name
   - Parse comma-separated strings into lists, strip whitespace
   - Validate each email address format using a simple regex (contains @ and at least one dot after @)
   - On validation error: return recipient_card.html partial in edit mode with errors, status 422
   - On success:
     a. Read .env file content
     b. Update (or add) the relevant env vars:
        - REPORT_RECIPIENTS_{ROLE_UPPER}={comma_separated_to}
        - REPORT_RECIPIENTS_{ROLE_UPPER}_CC={comma_separated_cc}
        - REPORT_RECIPIENTS_{ROLE_UPPER}_BCC={comma_separated_bcc}
     c. Write updated .env file
     d. Clear the lru_cache on get_settings so changes take effect: get_settings.cache_clear()
     e. Return recipient_card.html partial in display mode (edit=False)

IMPORTANT for .env update logic:
- Use regex to find and replace existing lines matching the env var pattern
- If a line doesn't exist yet, append it to the end of the file
- Preserve all other .env content unchanged
- Handle edge case where .env file doesn't exist (create it)
- Use Path from pathlib for file operations
