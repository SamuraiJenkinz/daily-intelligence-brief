  <name>Task 1: Create FTS5 migration and ArticleSearchService</name>
  <files>scripts/migrate_006_fts5.py, app/services/search.py</files>
  <action>
1. Create `scripts/migrate_006_fts5.py` following the pattern from migrate_003:
   - Add project root to sys.path
   - Import engine from app.database
   - Create FTS5 virtual table:
     ```sql
     CREATE VIRTUAL TABLE IF NOT EXISTS articles_fts USING fts5(
         title,
         description,
         summary,
         content=news_articles,
         content_rowid=id,
         tokenize='porter unicode61'
     );
     ```
   - Create three triggers to keep FTS5 in sync:
     - articles_fts_ai: AFTER INSERT on news_articles -> INSERT into articles_fts
     - articles_fts_au: AFTER UPDATE on news_articles -> DELETE old + INSERT new in articles_fts
     - articles_fts_ad: AFTER DELETE on news_articles -> DELETE from articles_fts
   - Backfill existing data: INSERT INTO articles_fts(rowid, title, description, summary) SELECT id, title, COALESCE(description,''), COALESCE(summary,'') FROM news_articles
   - Print progress messages like migrate_003
   - Handle "already exists" errors gracefully (skip with message)

2. Create `app/services/search.py` with ArticleSearchService class:
   - `search(db, query, role=None, date_from=None, date_to=None, priority=None, source_name=None, limit=50, offset=0)` -> list of NewsArticle objects + total_count
   - Implementation:
     a. If query is provided:
        - Use FTS5 MATCH query with bm25() ranking: SELECT na.*, bm25(articles_fts) as rank FROM articles_fts fts JOIN news_articles na ON na.id = fts.rowid WHERE articles_fts MATCH :query ORDER BY rank LIMIT :limit OFFSET :offset
        - Sanitize query: escape special FTS5 characters (double quotes, parentheses) to prevent syntax errors. If query contains no operators, wrap each word with quotes for phrase-safe matching.
     b. If no query but filters are provided:
        - Fall back to standard SQLAlchemy query on NewsArticle with ORDER BY created_at DESC
     c. Apply post-query filters in Python (since roles is JSON text):
        - role filter: json.loads(article.roles) and check if role in list
        - date_from: article.published_at >= date_from (if published_at is not None)
        - date_to: article.published_at <= date_to
        - priority: article.priority == priority
        - source_name: article.source_name == source_name
     d. Return tuple: (filtered_articles, total_count)
   - `get_filter_options(db)` -> dict with available filter values:
     - roles: ["Brokers", "Leadership", "Compliance", "Underwriting"]
     - priorities: list of distinct priority values from database
     - sources: list of distinct source_name values from database
   - Use structlog for logging search queries and result counts

IMPORTANT: Handle the case where articles_fts table does not exist (migration not run) -- fall back to LIKE queries on title/description/summary with a log warning suggesting to run the migration.
  </action>
