  <action>
1. Create `app/schemas/admin.py` with Pydantic models:
   - `SourceCreate(BaseModel)`: name (str, min_length=1, max_length=255), url (str, min_length=1), source_type (Literal["apify", "rss"]), actor_id (str | None = None), enabled (bool = True)
   - `SourceUpdate(BaseModel)`: name (str, min_length=1, max_length=255), url (str, min_length=1), source_type (Literal["apify", "rss"]), actor_id (str | None = None), enabled (bool = True)
   - Add field_validator for source_type to ensure valid values

2. Add source management routes to `app/routers/admin.py`:
   - GET /admin/sources -> list all sources, render sources.html (full page) or source_table.html (HTMX partial)
     - Accept optional query params: search (str), enabled_filter (str: "all"/"true"/"false")
     - Query Source model with filters applied
     - Check HX-Request header for partial vs full page response
   - POST /admin/sources/create -> validate with SourceCreate, create Source record, return source_table.html partial
     - Accept Form(...) parameters matching SourceCreate fields
     - On validation error: return source_form.html partial with errors and status_code=422
     - On success: return full updated source_table.html partial
   - GET /admin/sources/{source_id}/edit -> return source_edit_row.html partial (inline edit form)
   - POST /admin/sources/{source_id} -> validate with SourceUpdate, update Source record, return source_row.html partial
     - On validation error: return source_edit_row.html with errors
     - On success: return updated source_row.html (replaces edit row with display row)
   - POST /admin/sources/{source_id}/toggle -> toggle source.enabled, return source_row.html partial
   - DELETE /admin/sources/{source_id} -> delete source, return empty string (HTMX removes row)
     - Return HX-Trigger header with "showToast" event for success notification

All routes use response_class=HTMLResponse. All use SessionLocal() with try/finally for DB session management. Import Source from app.models.source.

IMPORTANT: Keep all existing routes intact. Add new routes below existing ones.
