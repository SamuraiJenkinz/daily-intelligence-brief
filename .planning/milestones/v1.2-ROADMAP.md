# Milestone v1.2: Factiva Knowledge Integration

**Status:** SHIPPED 2026-02-27
**Phases:** 14-16
**Total Plans:** 8

## Overview

Replace the Apify web scraping collection layer with BrasilIntel's proven FactivaCollector, making Factiva/Dow Jones the sole news source via MMC Core API. This milestone ports the mature 456-line FactivaCollector (pagination, body-fetch fallback, retry, event tracking), removes all Apify infrastructure, simplifies the pipeline to a single collection path, and updates the dashboard for the new Factiva-only architecture.

## Milestone Summary

**Key Decisions:**
- default-date-range-48h: Use 48h lookback (BrasilIntel proven approach) vs. 24h (current MDInsights)
- api-param-mapping: Use correct MMC Core API param names (industry, company, query) validated by BrasilIntel
- inline-article-storage: Extract article storage from ApifyCollector into PipelineOrchestrator._store_articles()
- preserve-db-schema: Keep SourceType.APIFY enum and defaults for DB compatibility
- binary-news-status: News API shows healthy/offline only (no degraded state since no fallback exists)
- honest-disable-warning: Replace misleading 'fallback to Apify/RSS' hint with honest 'stops all collection' warning

**Issues Resolved:**
- Fixed FactivaCollector API parameter names (industryCodes/companyCodes/keywords were wrong)
- Fixed keyword joining (space-join to OR-join for broader coverage)
- Fixed URL encoding for article IDs with special characters
- Eliminated 1,443 lines of dead Apify/RSS code
- Removed 2 unused dependencies (apify-client, feedparser)

**Issues Deferred:**
- Staging credentials needed to validate Factiva industry codes on deployment machine
- Industry code i832 is inferred — validate for production use
- TD-01: Admin trigger routes don't pass TokenManager (medium severity, non-production)

**Technical Debt Incurred:**
- SourceType.APIFY enum preserved in source.py for DB compatibility (existing rows)
- collector_source default="Apify/RSS" preserved in news_article.py (avoid migration risk)
- NEWS_FALLBACK enum defined but excluded from queries (DB compatibility)
- sources/base.py retains apify_client parameter in abstract interface (future extensibility)
